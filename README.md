# Barbearia App (Flutter + Firebase)

Aplicativo completo para gestão de barbearias, desenvolvido em Flutter com backend em Firebase Firestore.

Funcionalidades principais

Agendamento em tempo real

Cancelamento de agendamentos

Painel de administração para personalização de serviços, preços e horários

Geração de gráficos e relatórios de rendimento

Persistência de dados e sincronização via Firestore

Tecnologias e arquitetura

Flutter / Dart

Firebase Firestore

Gerenciamento de estado (ex: Provider, Riverpod, BLoC — conforme implementação)

Pacotes de gráficos (ex: charts_flutter, fl_chart ou similares)

Motivação

Projetos como Barbershop App mostram interfaces de gerenciamento para barbearias com fluxo de agendamentos e controle de serviços. 
GitHub

Outros projetos utilizam Firebase para CRUD e autenticação em apps de agendamento.

Como usar / executar localmente

Clone o repositório

Configure seu projeto Firebase (Firestore, autenticação, regras)

Insira as credenciais/configurações no projeto Flutter

Execute flutter pub get

Rode flutter run
